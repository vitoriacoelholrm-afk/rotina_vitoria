# rotina_vitoria

Página HTML de rotina pessoal da Vitória — single file, sem dependências externas.

## Estrutura

Arquivo único: `rotina_vitoria.html`

### Abas

| Aba | Descrição |
|-----|-----------|
| Treino | Exercícios do dia com checklist e barra de progresso |
| Estudos | Matérias programadas por dia da semana |
| Hábitos | Hábitos diários com check interativo |
| Semana | Resumo semanal de treinos, estudos e hábitos |
| Mês | Calendário mensal com tipo de treino por dia |
| Sugestões | Dicas de estudo por matéria (apps, podcasts, séries, YouTube) |

### Grade semanal de treinos

| Dia | Treino | Tipo |
|-----|--------|------|
| Segunda | Treino B | Superior (Ombros, Costas, Braços) |
| Terça | Descanso | — |
| Quarta | Treino D | Superior (Peito, Costas, Core) |
| Quinta | Treino A | Inferior + Aeróbico |
| Sexta | Treino C | Inferior (Glúteos, Adutores, Panturrilha) |
| Sábado | Aeróbico | Cardio leve a moderado |
| Domingo | Descanso | — |

### Matérias de estudo

| Dia | Matéria |
|-----|---------|
| Segunda | Inglês |
| Terça | Espanhol |
| Quarta | — |

| Sexta | Espanhol + Geografia |

## Estado

O estado (exercícios marcados, estudos, hábitos) é mantido em memória — não persiste entre recarregamentos da página.
